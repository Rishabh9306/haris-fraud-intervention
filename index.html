⚡ Call Flow (90 seconds end-to-end)
1
Outbound call initiated
Fraud signal received → HARIS calls in customer's preferred language within 15 sec
2
Zero-knowledge verification
Identity confirmed via challenge flow (last transaction amount, Emirates ID suffix). No PIN ever requested.
3
Fraud context delivered
Plain-language description of the anomaly. Customer confirms or disputes.
4
Card freeze executed
GUARD sub-agent calls freeze webhook (its only permitted action). SMS confirmation sent.
5
Warm transfer to human agent
Full context packet (transcript, action taken, language, verification result) handed to fraud team.

Tool scoping enforces compliance structurally — GUARD cannot call any irreversible action because those tools are not registered in its scope. This is a system property, not a prompt.
